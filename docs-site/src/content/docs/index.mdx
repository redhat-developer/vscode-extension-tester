## What ExTester does for you

<CardGrid>
	<Card title="Downloads VS Code" icon="download">
		Fetches a test instance of Visual Studio Code — any supported version, stable or insiders.
	</Card>
	<Card title="Handles ChromeDriver" icon="setting">
		Downloads the exact ChromeDriver build matching the VS Code instance, automatically.
	</Card>
	<Card title="Packages your extension" icon="seti:npm">
		Packs and installs your extension into the downloaded VS Code instance.
	</Card>
	<Card title="Runs your tests" icon="rocket">
		Launches VS Code under Selenium WebDriver and runs your Mocha-based UI tests against it.
	</Card>
</CardGrid>
