# Run tests and read the results

- **Run** everything, a folder, a file, a `describe` block or a single test from the Testing view, or from the gutter icon next to each `describe` and `it` in the editor. **Run Tests in Current File** runs the file you are editing.
- **Debug** a test to stop at breakpoints in it. Mocha's timeouts are off while you debug.
- **Stop** and **Rerun** are in the Testing view toolbar. One run starts at a time.
- Each test shows whether it **passed**, **failed** or was **skipped**.
- A failure shows the error, a diff of expected and actual values, a clickable stack trace and a thumbnail of ExTester's screenshot. Click the thumbnail to open the full image.
- **Test Results** shows the output of the run and of each test.
